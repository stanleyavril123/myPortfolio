# Résumé sources

Editable English and French LaTeX sources share `resume-style.tex`. The
portfolio downloads use `public/StanleyAvril_CV_EN.pdf` and
`public/StanleyAvril_CV_FR.pdf`.

With Tectonic installed, rebuild both from the repository root:

```sh
bash scripts/build-resumes.sh
```

Set `TECTONIC` to a compiler path if it is not on your PATH. On Overleaf,
upload the three `.tex` files, select XeLaTeX, and choose the English or
French résumé as the main document.

Content is based on the portfolio and the previous résumés. Graduation is
fall 2027. The résumé retains the Propolys experience and focuses projects
on CodeCell, SpaceMind, and SMS Booking. No new performance metrics were
invented. Update both languages when changing dates or experience.
